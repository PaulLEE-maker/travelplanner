# Hwan & Bom 여행 플래너

별도 빌드가 필요 없는 정적 PWA입니다. `index.html`과 같은 디렉터리를 HTTPS로 배포하면 됩니다.

## 홈 화면 앱 업데이트 방식

- 홈 화면 앱을 열거나 백그라운드에서 다시 돌아오면 최신 `index.html`을 캐시 없이 확인합니다.
- 새 버전이면 화면 코드만 다시 불러옵니다. 여행 데이터가 저장된 `localStorage`와 Firebase 데이터는 삭제하지 않습니다.
- 네트워크가 없으면 서비스 워커가 마지막으로 정상 수신한 앱 화면을 제공합니다.
- 설정의 **지금 업데이트 확인** 버튼으로 수동 확인도 가능합니다.

## 배포할 때

코드를 배포하는 커밋에서는 `version.js`의 버전을 반드시 올립니다.

예: `2026.09.08.1` → `2026.09.08.2`

이 파일은 매우 작아서 앱이 열리거나 다시 활성화될 때마다 부담 없이 확인할 수 있습니다. 버전 변경이 설치된 홈 화면 앱에 새 배포가 있다는 신호가 됩니다. 서비스 워커는 HTTPS 또는 localhost에서만 동작합니다.
